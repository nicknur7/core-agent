# Backlog

Single source of truth for what's queued. Sections:

## 🟢 READY

Work that can start now. One bullet per item.

## 🟡 GATED

Work blocked by a decision, an external party, or a trigger. Note the gate.

## 🔴 RESEARCH FIRST

Work that needs scoping before estimation.

## ⚪ PARKED

Work explicitly deferred. Note the re-trigger condition.
