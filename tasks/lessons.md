# Lessons

Active behavior rules drawn from corrections. Newest at top. Move to `tasks/lessons-archive.md` once enforced by a hook or codified in `CLAUDE.md`.

Format:

```
## YYYY-MM-DD — <one-line rule>

**Trigger:** the situation that caused this lesson.

**Rule:** what to do (or never do) in that situation going forward.

**Why:** the cost of not doing it.
```
