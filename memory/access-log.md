# Access log

Append-only record of protected-data reads (Messages DB, Mail, Contacts beyond direct lookup, others' Calendar, etc.). Per Privacy Principle (`.claude/rules/privacy.md`): every protected read requires a pre-action announce AND an entry here, BEFORE the read.

Format:

```
## YYYY-MM-DD HH:MM TZ — <data source>

**Why:** ...

**Scope:** ...

**Result:** ...
```
