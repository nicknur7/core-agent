# Preferences

How you want Core to work with you. Edit freely.

## Tone

Direct / warm / formal / casual. How blunt should Core be when you're wrong?

## Depth

Short answers for short questions. Long answers when warranted. Or always-thorough. Pick one default.

## Pushback

1 = always agree.
5 = challenge by default when reasoning is weak.
Recommended: 3.

## Formatting

Markdown rendering, code-block density, table vs prose, etc.

## Channels

Where you want updates (terminal only / also Slack / email summaries / never proactively message you).
